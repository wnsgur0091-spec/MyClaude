# Brickrise (브릭라이즈)

고객이 사진 1장을 올리면 피사체를 1x1 디폼블럭 큐브로 재현한 맞춤 조립 키트를 만들어 파는 서비스의 웹사이트 프로젝트입니다.
판매는 네이버 스마트스토어에서, 시안 생성은 브릭라이즈 자체 웹사이트에서 합니다.

결정 사항·규칙·1차 개발 범위는 [`CLAUDE.md`](./CLAUDE.md)에 정리되어 있습니다.

## 역할 분담

- **웹 홈페이지 (이 폴더)**: 고객 화면(형태·크기 선택, 동의, 사진 업로드, 시안 확인, 주문 코드 발급), 무료 횟수 제한, 관리자 주문 검증 화면
- **생성형 AI 파이프라인 (타 팀원 개발 중)**: Image → 3D, 3D → Brick 변환. 웹은 이 파이프라인을 API로 호출하는 구조로 연결 예정

## 폴더
