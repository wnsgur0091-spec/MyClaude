브릭라이즈 고객 경험 플로우

1. 알게 되기 네이버 스토어

1
네이버

네이버 스토어 상세페이지 방문

  • 평면/입체 예시 이미지, 사이즈(5/10/15cm), 가격 계산 방식 (기본 제작비 + 블럭 수 × 단가)
  • 사용 부품 “MYTOYS 디폼블럭 사용” + 제휴 관계 없음 문구
  • KC 신고번호, 사용 연령, 작은 부품 경고, 사업자 정보
  • 주문제작 상품 청약철회 제한, 시안과 실물 차이 안내 (주문서에서도 확인)
  • 문의 창구: 네이버 톡톡
2
고객

‘내 브릭 만들기’ 링크를 눌러 브릭라이즈 사이트로 이동

로그인 없이 바로 시작합니다.

2. 시안 만들기 브릭라이즈 사이트

3
고객

형태와 크기 선택

평면(사진 그대로 픽셀 아트) 또는 입체(AI 3D 모델 기반), 5×5 / 10×10 / 15×15cm 중 선택

4
고객

사진 올리기 전 동의 (필수 4개 + 선택 1개)

사진을 받기 전에 동의를 받아야 해서 업로드 직전에 한 번만 받습니다. 항목은 오른쪽 ‘동의 항목’ 패널에 있습니다.

5
고객

촬영 가이드를 보고 사진 1장 올리기

  • 밝은 곳에서, 피사체가 화면을 크게 채우고 잘리지 않게
  • 배경은 시안 생성 단계에서 AI가 자동으로 지움 (고객 작업 없음)
6
사이트

업로드 화면 고지

  • “사진을 바탕으로 AI가 3D 모델을 생성합니다” (AI 기본법)
  • 사진 보관·파기 기간 요약, 오늘 남은 무료 시안 횟수 표시

사진 품질 자동 검사를 통과했나요? (밝기·흐림·피사체 크기·해상도)

아니오재촬영 안내 후 5번으로. 무료 횟수는 차감하지 않음
예다음 검사로 진행

오늘 남은 무료 시안 횟수가 있나요?

아니오“내일 다시 이용해 주세요” 안내. 하루 전체 AI 예산 상한 도달 시에도 일시 중지
예시안 생성으로 진행
쿠키 기준 하루 3회 + IP 기준 넉넉한 상한 (오른쪽 ‘무료 횟수 규칙’ 패널)
7
사이트

AI 시안 생성 (무료 횟수 1회 차감)

  • 공통: 배경 자동 제거
  • 입체: 사진 → 3D 모델(상용 API) → 디폼블럭 배치 / 평면: 사진 → 픽셀 배치
  • 39색 중 36색 자동 배색, 내부 채움, 떨어지는 조각 제거
  • 같은 사진·옵션으로 다시 만들면 저장된 결과를 보여주고 횟수는 차감하지 않음
8
고객

시안 결과 확인

  • 시안 이미지 (“AI 생성 예시” 표시), 완성 크기, 총 블럭 수, 사용 색상 수
  • 가격: 기본 제작비 + 블럭 수 × 블럭 단가
  • 색상별 부품 목록과 조립 설명서는 결제 후 제공 (비공개)

시안이 마음에 드나요?

아니오사진·형태·크기를 바꿔 다시 (남은 횟수 안에서)
예주문 단계로 진행

3. 주문·결제 사이트 → 네이버

9
사이트

주문 코드 발급

  • 형식: BR-3D10-K7Q2 (3D=입체 / 2D=평면, 10=크기 cm, 뒤 4자리 무작위)
  • 7일 유효, 1회용. 서버에 시안·블럭 수·금액과 함께 저장
  • “옵션 ‘입체 10cm’ 선택, 추가상품 ‘블럭 10개’ 수량 30, 주문 코드 칸에 코드 붙여넣기” 안내
  • 코드 복사 버튼, 네이버 상품 페이지로 이동 버튼
10
네이버

옵션·수량 선택, 주문 코드 입력 후 결제

  • 옵션 6개: 평면/입체 × 5/10/15cm (기본 제작비)
  • 추가상품 ‘블럭 10개’ 수량 입력
  • 텍스트 입력형 옵션에 주문 코드 입력
  • 청약철회 제한·시안과 실물 차이는 네이버 상품 페이지·주문서에서 고지

4. 검증·제작·배송 운영자

11
사이트

주문 코드 자동 검증

  • 코드 확인: 발급된 코드인지, 7일 이내인지, 처음 쓰는지
  • 옵션 일치: 결제한 옵션 = 코드의 형태·크기 (예: 3D10 = 입체 10cm)
  • 수량 일치: ‘블럭 10개’ 수량 = 시안 블럭 수 ÷ 10 (올림)
  • 금액 확인: 결제 금액 = 시안 금액
처음에는 운영자가 판매자센터 주문 목록의 코드를 관리 화면에 넣어 확인하고, 주문이 늘면 커머스 API로 자동화

네 가지가 모두 맞나요?

아니오네이버 톡톡으로 안내. 옵션 불일치: 취소 후 재주문 / 수량 부족: 차액 결제 요청 / 수량 초과: 부분 환불 / 코드 오류: 올바른 코드 확인
예판매자센터에서 ‘발주 확인’ 처리
12
운영

피킹

  • 색상별로 무게를 재서 개수 확인 (블럭 1개 무게 기준)
  • 색상별 여분 약 5%(최소 2개) 추가
13
사이트

설명서 PDF 생성 → QR 안내지 인쇄

  • 주문마다 설명서 PDF를 한 번만 만들어 파일 저장소에 저장 (서버 계산은 이때 한 번뿐)
  • QR은 그 PDF 파일 주소로 연결. 추측할 수 없는 주소, 일정 기간 보관
  • 안내지 내용: QR 코드, 완성 크기·총 블럭 수, 주문 코드, 네이버 톡톡 문의 안내
14
운영

포장

  • 색상별 소분 봉투, QR 안내지 1장 (흑백 인쇄)
  • 박스 인쇄: KC 신고번호, 제조자 정보, 사용 연령, 작은 부품 경고 (QR로 대체 불가)
15
네이버

발송 처리

판매자센터에 송장 번호를 등록하면 고객에게 배송 알림이 갑니다.

5. 조립과 그 이후 고객

16
고객

QR을 찍어 PDF 설명서 열기

  • 1쪽: 완성 이미지, 색상별 블럭 수 (봉투와 비교)
  • 2쪽부터: 아래층부터 한 층씩, 위에서 본 칸 지도 + 이번 층 색상별 개수
  • 칸마다 색상 번호 표기 (흑백 인쇄해도 구분 가능), 휴대폰에 저장해 두고 보기
17
고객

완성하고 리뷰 작성

블럭이 모자라면 네이버 톡톡으로 문의 (주문 코드 함께) → 여분으로 우선 해결, 필요하면 추가 발송

18
사이트

데이터 처리

  • 보관 기간이 지나면 원본 사진 파기 (설명서 PDF는 블럭 배치 정보만으로 만들어져 유지 가능)
  • IP는 원문 대신 변환값(해시)으로 짧게만 보관
  • 선택 동의한 고객만 사진·결과물을 서비스 개선·홍보에 활용
동의 항목 (어디서 받는지)
  1. 사이트개인정보 수집·이용
    올린 사진, 접속 IP·쿠키 · 목적 · 보관 기간
  2. 사이트개인정보 국외 이전
    해외 3D 생성 API 사용 시 이전 국가·업체·항목
  3. 사이트업로드 사진 권리 보증
    본인 소유 또는 권리가 있는 사진, 타인 저작물·초상 아님
  4. 사이트만 14세 이상 확인
    미만은 보호자 동의 후 이용
  5. 선택AI 이미지 활용
    사진·결과물의 서비스 개선·홍보 활용
  6. 네이버주문제작 청약철회 제한
    상품 페이지·주문서에서 고지
  7. 네이버시안과 실물 차이
    상품 페이지·주문서에서 고지
  • 사이트 항목은 사진을 받기 전(업로드 직전)에 받아야 하고, 네이버가 대신 받을 수 없음
  • 개인정보 항목을 ‘고지’로 바꿀 수 있는지는 변호사 자문으로 확인
가격 계산

총액 = 기본 제작비(형태·크기) + 블럭 수 × 블럭 단가

  • 사이트: 시안을 만들면 위 식으로 총액을 바로 계산해 표시
  • 네이버: 옵션 6개(형태·크기)에 기본 제작비, 추가상품 ‘블럭 10개’에 10개 단가를 등록하고 고객이 수량 입력
  • 예: 블럭 829개 → ‘블럭 10개’ 수량 83 (올림)
기본 제작비 구성 (원가 기준)
상품안내지박스·봉투택배생성합계
평면 5cm1001,0003,5001004,700
평면 10cm1001,5003,5001005,200
평면 15cm1002,0003,5001005,700
입체 5cm1001,5003,5002,0007,100
입체 10cm1002,0003,5002,0007,600
입체 15cm1002,5003,5002,0008,100
  • 단위: 원. 생성 = 평면 픽셀 변환 / 입체 3D 생성 API (미구매 시안 비용 포함 추정)
  • 피킹·포장 인건비 0원 (자체 인력), 블럭 원가 개당 약 2.1원 + 여분 약 5%
  • 판매가에는 네이버 수수료 약 5.5%, 부가세 10%, 목표 이익을 더함
무료 횟수 규칙
  • 쿠키(기기 표시) 기준 하루 3회: 일반 고객을 정확히 셈
  • IP 기준 하루 15회 정도 넉넉한 상한: 쿠키를 지우며 반복하는 경우를 막고, 통신사·와이파이 공유 IP 고객은 막지 않음
  • 둘 중 하나라도 넘으면 시안 생성 중지
  • 같은 사진·옵션 재생성, 품질 검사 불합격은 차감 없음
  • 하루 전체 AI 비용 상한(예: 3만 원) 도달 시 일시 중지
  • 필요하면 무료 자동입력 방지(Cloudflare Turnstile) 추가
주문 코드 규칙
  • 형식: BR-3D10-K7Q2 (형태·크기 + 무작위 4자리)
  • 7일 유효, 1회만 사용
  • 코드에 시안, 블럭 수, 옵션, 금액 정보 연결
  • 코드 복사 버튼으로 입력 실수 줄이기
확인·결정 대기
  • 변호사 자문: 개인정보 동의 방식, 만 14세 확인 필요 여부, 캐릭터 모양 재현 가능 여부
  • 사진 1장 방식 기술 검토 (입체 품질)
  • 네이버 판매자센터: 외부 사이트 연동, 주문 코드·추가상품 수량 방식, 주문제작 상품 설정
  • 기본 제작비와 블럭 단가 확정
  • 사진·설명서 PDF 보관 기간
  • KC 안전확인 시험기관 견적 (36색 한 모델 가능 여부)
